# Lenny's Torrent Downloader

Windows 本地种子下载器，当前版本 **0.16**。

## 启动

直接运行 **LennyTorrentDownloader.exe**，无需另外安装 Python。本机文件在 `dist/`，Start.cmd 会优先打开该 EXE。

后续更新使用相同 EXE 文件名，在窗口和文件属性内递增版本号。替换前先退出正在运行的程序，原任务数据和下载位置继续保留。

使用提供的 Logo 作为主界面、窗口和系统托盘图标。点击最小化按钮或“收起到托盘”后，下载继续进行。单击或双击托盘图标恢复窗口；右键菜单可以显示窗口或“退出并停止下载”。点击窗口右上角 X 仍会正常退出。Windows 可能将图标放在任务栏右侧的隐藏图标区域（向上箭头内）。无系统托盘时保留普通最小化行为。

从源码开发时，安装 Python 3.13 x64 后运行 Setup.cmd。依赖安装需要网络；调试启动使用 `.venv\Scripts\python.exe app.py`。

## 下载与播放

- 添加或拖入 .torrent，可勾选文件和保存目录。
- “添加磁力链接”接受 magnet:? 地址，也支持拖入磁力链接和启动参数。首先获取元数据，再自动选择视频；没有视频时选择全部普通文件。磁力链接找不到来源时，获取文件信息也会等待。
- “播放”列显示起播缓冲进度。选中文件中最大的一个视频准备好后出现 ▶ 播放，进入内置窗口。
- 起播需要视频开头约 2 MiB 和末尾约 1 MiB 的相关分片全部校验通过。小文件可能需要下完后才达到条件。这是字节缓冲门槛，不是流畅播放保证。
- 播放时按读取位置优先获取分片，支持暂停播放、音量和时间跳转。跳转到未下载位置会等待；45 秒取不到当前分片时连接会结束，可继续下载后重新打开。
- 0.11 边下边看为实验功能。实际兼容性受容器、编码、索引布局和下载速度影响；MP4 已完成真实部分下载播放测试，不能保证所有 MKV、AVI 或编码都支持。
- 已完成任务双击后用系统默认应用打开。多文件任务会显示选择列表。

## 暂停、停止和删除

| 操作 | 行为 |
|---|---|
| 暂停 | 暂停传输，保留任务在引擎中，再点开始可继续 |
| 停止 | 保存续传状态后将任务移出引擎，释放相关连接和资源；任务记录及文件保留 |
| 开始 | 暂停任务恢复；停止任务重新载入后续传，必要时校验 |
| 删除任务 | 默认仅移除记录，保留文件 |
| 勾选同时删除文件 | 永久删除该种子对应的文件，不进入回收站；同目录无关文件保留 |

暂停、停止、删除某任务会关闭它的播放窗口。关闭主窗口保存任务并停止下载。停止状态重启后保持停止。

关闭播放窗口会释放播放内存缓冲和读取请求。播放器不另建一份视频缓存文件：下载目录中的未完成视频属于下载任务，正常关闭程序时保留以便续传。若要清理这部分内容，在删除任务时勾选“同时永久删除此任务已下载的文件”。

## 数据与升级

源码只保留一套：app.py 为界面，engine.py 为下载和任务管理，streaming.py 为本地媒体服务，player.py 为播放器，version.py 为名称和版本号。后续直接更新为 0.12、0.13，不另建 V1/V2 项目。

为兼容既有下载，本机数据继续使用 `%LOCALAPPDATA%\Torrent_V1\data`。这是历史内部数据路径，不是当前程序版本；重命名应用不会丢失任务。下载内容仍在各任务原来的保存目录。

旧源码和旧环境在 `%LOCALAPPDATA%\LennyTorrentDownloader\legacy` 留作回退备份。不要用旧版打开新格式任务数据。项目根目录固定用 Start.cmd。

## 开发和测试

安装 requirements-dev.txt 后双击 RunTests.cmd 运行整套基础回归，结果写入 docs/test-report.md。各套件在独立进程中运行，任何失败会立即停止并报错。

运行 `.venv\Scripts\python.exe -m unittest discover -s tests -p test_integration.py` 验证磁力元数据、暂停/停止、重启、未完成文件的 HTTP Range 读取、删除选项和无关文件保留。

可选播放测试：安装 requirements-dev.txt 后执行 `.venv\Scripts\python.exe tests/test_playback.py`，自动生成测试视频并验证文件尚未完整下载时能解码画面。不会播放个人下载内容。

媒体服务仅监听 127.0.0.1，使用随机访问令牌，读取 libtorrent 已校验的分片，不把稀疏文件空洞当作视频数据。

技术参考：[libtorrent 流媒体机制](https://libtorrent.org/streaming.html)、[Qt MediaPlayer](https://doc.qt.io/qtforpython-6/PySide6/QtMultimedia/QMediaPlayer.html)。

## 打包与版本管理

安装 requirements-build.txt 后运行 Build.cmd，输出固定名称 `dist/LennyTorrentDownloader.exe`。PyInstaller 单文件程序包含 Python、Qt 和下载引擎，首次打开会解压运行组件到系统临时目录，正常退出后由打包运行时清理。

修改 version.py 和 CHANGELOG.md → 运行 RunTests.cmd → 运行 Build.cmd → 验证 EXE → 发布新版本。构建配置及依赖版本保存在源码中。

GitHub 源码仓库为私有备份；EXE 放在 Release 附件，不进入源码历史。虚拟环境、构建缓存、生成的测试视频/截图及个人下载数据均不上传。自动化测试代码保留，便于后续回归。

正式公开开源前需确定项目许可证。依赖许可入口见 THIRD_PARTY_NOTICES.md。
